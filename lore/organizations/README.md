## 查詢與時間精度

1. 用組織 ID 查名錄，再於隸屬表的 `by_organization` 取得關係 ID，回到 `relations` 查人物與職務。
2. 用人物 ID 查 `by_character`，可沿同一組關係回到組織。愚者教會、海神教會及塔羅會各有 ID。阿爾傑的風暴教會神職、塔羅會成員及海神教會教宗分開記錄。
3. `chapter_span` 是情節定位，範圍內可能包含事件前後的提及。只有 `time_from`、`time_to` 是世界內日期，空值代表未確定。月份精度保留到月。塔羅會的既有日期來自二手資料，原作逐條確認仍待進行。跨時期名冊以可用日期判斷，未定日期的條目仍須查章節。
4. 人物的血緣、師徒、任職、信仰或合作可並存。母組織、子隊伍與派系以各自 ID 表示；史蒂夫追捕節制派、淨化者與第八局聯合調查等各有關係資料。

## 待核

候選條目的起訖、改組與名單完整性，以及標為 `pending_user_review` 的引文定位，仍待回查原作。此版的範圍是既有名錄及本次可追溯的補充，百科組織頁和資料庫條目可能涵蓋不同實體範圍。
