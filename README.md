# 《詭秘之主》世界觀與互動小說資料庫

> 非官方、私人使用的《詭秘之主》／《宿命之環》同人遊戲研究與設計資料庫。**Demo 階段已收束，進入正式版前期製作。**

新對話先讀[正式版製作規格](docs/FORMAL_EDITION_DESIGN.md)和[第一部文本工作計畫](game/events/part_one_writing_plan.md)。

## 已確認的作品方向

- 全畫面像素風互動小說。輸入名字後直接進入[廷根開場〈半袋煤〉](game/events/tingen_opening_story_v1.md)，跟著普通主角逐步接觸非凡事件。
- 立繪與逐字台詞帶出人物與情節。選項寫成主角說出口的話，重要場面安排演出和 CG。
- 支線由後續場景帶來邀請、危機或機會。原作是零介入基準，有效干預可改變後續主支線。
- 第一個製作樣板從廷根開場做到第一個選擇結算；詳細介面、美術與製作估算見[正式版製作規格](docs/FORMAL_EDITION_DESIGN.md)。

## 編輯工作流
1. 修改前先讀取 GitHub 最新內容，避免覆蓋彼此變更。
2. 每個原作事實標註來源、章節（如已知）與核驗狀態。
3. 沒有核實的資訊可以收錄為 `needs_verification`，**不可當作已確認的原作事實**。
4. 重大歷史／劇情更動記錄決策與影響，禁止默默改動原作時間線。
5. 每次提交只做可追蹤的一類變更；GitHub 會保留歷史。

## 內容與版權
原作文本不整章轉載；盡量以自己撰寫的摘要、設定欄位與引用章節索引考據。未取得授權前不應視為可直接商用。
