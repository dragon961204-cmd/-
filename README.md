# 《詭秘之主》世界觀與互動文字小說資料庫

> 非官方、私人使用的《詭秘之主》／《宿命之環》同人遊戲研究與設計資料庫。**目前暫停 Demo 開發，進行第一部文本規劃。**

新對話請從[第一部文本工作計畫](game/events/part_one_writing_plan.md)接續。該頁記錄已確認設定、待議設計與下一批文本。

## 已確認的作品方向

- 互動文字小說。輸入名字後從廷根開場，讀者跟著對詭秘世界一無所知的主角逐步接觸非凡事件。
- 正文在關鍵抉擇停下。讀者的決定會留在世界中，支線由後續場景帶來邀請、危機或機會。
- 原作是零介入基準。主線和支線共用實際結果，角色依各自的知情來源行動。
- 考據涵蓋《詭秘之主》與《宿命之環》，先集中在第五紀 1349 年的世界。

## 編輯工作流
1. 修改前先讀取 GitHub 最新內容，避免覆蓋彼此變更。
2. 每個原作事實標註來源、章節（如已知）與核驗狀態。
3. 沒有核實的資訊可以收錄為 `needs_verification`，**不可當作已確認的原作事實**。
4. 重大歷史／劇情更動記錄決策與影響，禁止默默改動原作時間線。
5. 每次提交只做可追蹤的一類變更；GitHub 會保留歷史。
