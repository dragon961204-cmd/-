# 角色收錄與背景撰寫標準 v0.1

## 不再追求索引全部 1,368 筆
中文人物索引 https://lotmfanwiki.com/type/p.html 標示 1,368 個人物索引條目，但包含別名、短暫登場人物、未定名角色與只有一次提及的人。
首頁 https://lotmfanwiki.com/ 另外列出 278 個主要人物，可做**重要角色候選池**，不是必須納入的固定上限。

## 是否值得收錄與深寫
- **A / 核心（完整背景）**：兩部主角、塔羅會重要人物、神明/天使/重大歷史人物、主要勢力領導者、左右原作主線的角色。
- **B / 地區主線（完整背景）**：廷根值夜者、玫瑰學派兩派骨幹、科爾杜與特里爾主線主要參與者。
- **C / 功能 NPC（精簡背景）**：職務或事件有用但故事不多者。保留身分、首次登場、所屬機構、主要事件、兩三句背景。
- **D / 不收錄或合併**：無名路人、純提及名字、僅一場無延伸功能人物、同一人物的別名；除非某任務需要再補。
- **不以台詞或篇幅作唯一評斷**：有些出場很短的人物卻是關鍵線索或因果節點。

## 背景資料欄位
1. 人物唯一ID和別名；2. 出身背景、階級/職業、關係；3. 首次登場及所屬年代；4. 組織與身分變遷；5. 非凡途徑／序列（分時期）；6. 動機、重大經歷、角色發展；7. 與其他人物的關係；8. 出場城市與時間；9. 玩家可遇到的前提與情報遮蔽；10. 考據來源與可靠度。

## 禁止以後期身分覆蓋初期
- 1349廷根起步時，倫納德是值夜者而不是直接開放後期塔羅會與紅手套身份。
- 卷毛狒狒研究會在1352年以後成立，1349不可出現該組織。
- 1349年塔羅會成立時點與成員加入節點，需要精確按日期核對。
- 歷史已故人物應以書籍、日記、遺址和故事記錄出現，不能任意在城市遇到。

## 權利與品質
- 自行撰寫摘要，不複製小說長篇原文。
- 二手wiki來源只是考據導航，只有原作章節已核查後才能升為 `verified`。
- 對NPC的遊戲用途屬**原創遊戲設計**，不可當原作實際發生事件。
- 如發現百科不同版本矛盾，保留 `needs_verification` 並列出疑點。
