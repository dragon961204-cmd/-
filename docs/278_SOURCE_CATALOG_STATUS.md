來源： https://lotmfanwiki.com/type/p.html

截至 2026-11-11，站點首頁標示 **278個人物獨立頁面／1368個人物索引行**。
網頁搜尋摘要可見部分已發表頁名，但無法取得足夠完整的頁面 HTML，因此目前不能誠實地宣稱已擷取278個正確連結。

已先建：`lore/characters/source_page_catalog_seed_v0.1.json`（23個可從搜尋頁面辨識的候選標題，含20個暫時映射到既有人物ID）。
完整擷取工具：`scripts/import_lotm_278.py`，需要從能連線外部網站的環境執行；擷取**表格名稱欄加粗且有連結**的條目，只有精確匹配278頁才落盤，若站點更改版面將明確失敗。

**注意**：百科把「真實造物主」和「遠古太陽神、亞當」當作同頁別名時，不能因此斷定全是同一個可互換人物ID。這是遊戲世界觀的重要身份拆分問題，需專門做身份圖。
