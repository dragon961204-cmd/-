## 審核時最省力的做法
使用者只需指出「角色名 + 哪一項錯誤 + 正確事實」，例如「卡拉曼的中文版名稱是……」「某角色不是值夜者」「某序列時期應調整」。AI再將更正同步到人物、關係、途徑與時間線表。未被點名的角色保持待審，不暗示全部正確。
