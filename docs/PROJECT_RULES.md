# 遊戲規則與開發決策（v0.2）

## 已確認

- 第一部採章節式像素互動小說。場景承接主線和支線，地點與時間隨故事推進。正式介面與演出詳見[正式版製作規格](FORMAL_EDITION_DESIGN.md)。
- 主畫面輸入名字後直接進入[〈半袋煤〉](../game/events/tingen_opening_story_v1.md)。主角起初是廷根工人家庭的普通人，因艾德失蹤捲入異常事件，透過親歷、證詞和查證逐步認識非凡世界。
- 選項寫成主角親口說出的台詞。支線由後續場景中的邀請、危機或機會引出；邀請者必須有動機、有資格且仍能聯絡。赴約、加入組織、取得配方與實際服藥各自結算。
- 同一事件只結算一次。主支線讀取共用的人物去向、證物持有人和當期狀態。各角色的知情來源另外記錄。
- 原作是零介入的預設時間線。有效干預可以讓後續事件改寫或因前提消失而關閉。因斯若已在廷根死亡，西拜朗追逃不會沿原稿發生，0-08 後續依實際去向安排。
- 主角終究會成為非凡者。途徑、組織、社會地位及人際關係透過故事發展。考據包含《詭秘之主》與《宿命之環》，世界快照先以第五紀 1349 年為主。

## 待議

- 開場的確切日期、各章選項密度，以及回看或重讀分歧的方式。
- 各組織的具體入會條件，以及特殊組織可提供的接觸程度。

## 禁止混淆
「已確認遊戲設計」不代表「已確認原作設定」；兩者分開記錄。

## 資料庫優先政策（2026-11-11，confirmed）

1. 研究範圍包含《詭秘之主》第一部及《宿命之環》，允許完整劇透。
2. 優先打造完整可查詢、互相關聯的**人物、組織、途徑、地理、歷史事件**資料庫，不以遊戲可玩進度作驗收。
3. 人物重要性採 A/B/C/D 分級，百科所列278個獨立人物頁面是「候選母體」，須逐一收錄/排除/合併並附理由，**不是已確定278個必須逐字撰寫長篇傳記**。
4. A/B級需有可追溯的個人背景、重大經歷、關係、組織隸屬時間線、途徑晉升、結局；非原作明示者標 unknown，不可自行杜撰。
5. 驗收狀態分 `indexed`（建立ID）、`draft`（二手來源初稿）、`chapter_checked`（原作章節逐條核實）、`validated`（跨表、時序、別名核對）四級。**只用 validated 計算完成比例**。
6. 章節來源、可靠度、保密程度獨立標註；引用原作時只存章節索引與自行撰寫的摘要，不儲存整章受版權保護的小說。
7. 所有新增或修正應包含自動檢查結果及未解疑點，集中回報，避免每新增幾個角色就中斷。
8. 正式版按章使用現有考據資料。涉及劇情的待核資訊隨章核對，並保留原有的資料庫驗收標記。

## 考據分工修訂（2026-11-11，使用者確認）
- **使用者閱讀過原作全文，負責審核人物設定**。AI主要負責加速補齊候選名錄、背景初稿、組織／途徑／時間線欄位、提出疑點。
- AI不再為了逐章核對而暫停人物擴充；不做無用的短篇重複回報。
- 所有人物初稿採 `pending_user_review`，只有使用者明確確認的記為 `user_approved`；不可假冒使用者驗收。
- 可附維基或原作章節索引作導航，但不作「已逐章證實」宣稱；未知資訊保持未知。
