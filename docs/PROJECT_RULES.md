# 遊戲規則與開發決策（v0.1）

## 已確認（confirmed）
- 玩家終究必須成為非凡者。
- 創角：年齡自行輸入；家庭背景採隨機生成，可能影響初始機會。
- 玩家可通過後續人生選擇改變社會地位。
- 創角時不選擇途徑與組織；透過探索和事件取得選擇機會。
- 開放世界文字 RPG；玩家可到不同地區探索，觸發事件，走向不同勢力主線。
- 原作事件是預設時間線；玩家的有效干預會改變部分事件及後續世界狀態。
- 原作考據包含《詭秘之主》與《宿命之環》；允許完整劇透。
- **使用者正式選擇 B（2026-11-11）：先完成世界觀資料庫與重要人物傳記，暫不開始遊戲玩法、UI、美術或事件引擎開發。**

## 暫定（proposed）
- 每個遊戲日 **5 AP**；不同探索行為消耗不同點數。實際費用、恢復、跨城旅行另議。
- 優先建立第五紀 **1349 年**世界快照；玩家可使用的年代尚未最終鎖定。
- 重要事件可被玩家干預，但因果、能力與接觸門檻應嚴格。

## 待議（open）
- 角色創角時的具體年代、起始地點與年齡上下限。
- 死亡／重開／讀檔機制、行動點平衡。
- 組織入會條件，特殊組織是否僅提供接觸而不能正式加入。
- 南北大陸探索開放順序與遠距移動成本。

## 禁止混淆
「已確認遊戲設計」不代表「已確認原作設定」；兩者分開記錄。

## 資料庫優先政策（2026-11-11，confirmed）

1. 研究範圍包含《詭秘之主》第一部及《宿命之環》，允許完整劇透。
2. 優先打造完整可查詢、互相關聯的**人物、組織、途徑、地理、歷史事件**資料庫，不以遊戲可玩進度作驗收。
3. 人物重要性採 A/B/C/D 分級，百科所列278個獨立人物頁面是「候選母體」，須逐一收錄/排除/合併並附理由，**不是已確定278個必須逐字撰寫長篇傳記**。
4. A/B級需有可追溯的個人背景、重大經歷、關係、組織隸屬時間線、途徑晉升、結局；非原作明示者標 unknown，不可自行杜撰。
5. 驗收狀態分 `indexed`（建立ID）、`draft`（二手來源初稿）、`chapter_checked`（原作章節逐條核實）、`validated`（跨表、時序、別名核對）四級。**只用 validated 計算完成比例**。
6. 章節來源、可靠度、保密程度獨立標註；引用原作時只存章節索引與自行撰寫的摘要，不儲存整章受版權保護的小說。
7. 所有新增或修正應包含自動檢查結果及未解疑點，集中回報，避免每新增幾個角色就中斷。
8. 待世界觀資料庫達成約定驗收範圍後，再規劃玩法與事件引擎。
