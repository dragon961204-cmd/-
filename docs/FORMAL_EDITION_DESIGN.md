# 《詭秘之主》互動小說正式版製作規格

更新日期 2026-11-13。Demo 階段已收束。以下記錄正式版的方向和首輪製作估算。

## 閱讀畫面與操作

| 位置 | 功能 |
| --- | --- |
| 全畫面 | 場景背景填滿遊戲畫面。以桌機橫向構圖為主，手機維持可讀、可點。 |
| 左上 | 顯示當前地點與故事時間，隨場景更新。 |
| 中央 | 對話角色立繪。背景、立繪和演出可依場景變更。 |
| 下方 | 顯示說話者、逐字台詞和選項。點擊或空白鍵可補完當句、再推進。 |
| 右上選單 | 人物檔案、存檔／讀檔、回主頁、音樂開關。人物檔案依主角所知逐步更新。 |
| 左下背包 | 點開後查看當下持有的任務物品與線索；取得、移交和失去隨情節更新。 |
| 右下主角狀態 | 查看途徑、序列等已知狀態。主角起初是普通人，實際服藥後才更新途徑和序列。 |

手動存檔與自動續讀是首輪預設。存檔要能還原世界結果、知情、背包與進度，避免讀檔後出現前後矛盾。

## 劇本與分歧

- 主畫面輸入名字後直接讀[〈半袋煤〉](../game/events/tingen_opening_story_v1.md)。先讓玩家認識主角在廷根工人家庭的生活與關係，再由艾德失蹤和親歷的異常逐步揭開非凡世界。
- 每位重要人物初登場時，在場景內交代身分、與主角的關係和當下動機。為事件保留鋪陳、反應和收束。角色說出口的台詞就是對話選項。
- 支線由故事中的邀請、危機或機會發生。原作是零介入基準，主支線共用世界結果，角色知情依取得來源另記。因斯若在廷根死亡，依他存活的西拜朗追逃和 0-08 情節不能沿原稿觸發；後續依 0-08 的實際去向撰寫。
- 逐幕記錄場景 ID、地點與時段、出場者與動機、台詞、選項條件、結果、後續場景及演出素材。沿用既有主線、15 條長支線和 45 幕 IF 草稿，逐幕核對銜接和角色動機。

## 像素美術與演出

- 參照使用者提供的雨夜港口意象。以煤氣燈、冷青灰、雨、濕石和不成比例的巨大輪廓做成像素場景，保持前景人物和對話文字清楚。壓抑感由日常細節、停頓、光線、環境聲與異常逐步形成。
- 立繪依每章實際說話者安排。主要角色先做一張基礎立繪，再按必要場面補表情；具名配角按登場製作，跨章和 IF 線沿用；短暫 NPC 可共用職業剪影。使用者提供的正式立繪可替換暫用圖。
- 劇本標記表情、動作、停頓、音效與 CG 切入時機。震驚可用立繪短促抖動後停半拍。大場面和關鍵轉折安排全畫面像素 CG，例如第一次親眼看到非凡現象。共用場面的 CG 可以跨分歧重用，畫面內容確實改變時再做變體。

## 製作順序與估算

依[廷根正式版開場框架](../game/events/tingen_opening_framework_v1.md)，先將廷根開場到第一個重大選擇結算做成一段可玩的正式樣板，包含全畫面、選單、背包、存讀檔、一個立繪反應和一張 CG。確定文字與畫面的節奏後，沿用共用介面、存檔與演出程式，依實際登場順序擴寫廷根篇，再延伸至第一部八卷。

下列為規劃區間，假設沿用既有正文底稿、逐幕改寫、素材可重用，並計入寫作、程式、美術整合及人工檢查。各列為累計範圍。文字 token 合計估算讀入與輸出；美術以可用素材張數估算，重試另計。

| 範圍 | 文字／程式 token | 可用立繪、背景、CG | 有效工時 |
| --- | ---: | ---: | ---: |
| 正式開場樣板 | 8–20 萬 | 5–10 張 | 20–40 小時 |
| 完整廷根篇 | 35–100 萬 | 25–50 張 | 100–220 小時 |
| 第一部八卷 | 200–600 萬 | 100–220 張 | 650–1,400 小時 |

美術先按劇本列出使用者供圖、可沿用、可共用與需新製作的素材。正式樣板完成後，以實際幕數、每幕改稿時間及圖像重試率重估。每批僅載入當章劇本、直接依賴的因果與素材清單，可降低重讀長稿的用量。
