# 考據與資料品質規則

## 來源優先順序
1. 原作小說具體章節與作者公開設定（記錄章節/來源）。
2. 有明確引文或章節索引的可靠百科資料（用來尋找原作依據）。
3. 其他社群討論與合理推論（只能標記為待核實）。
4. 遊戲原創敘事與機制（不得寫成原作已明說）。

## 每筆世界觀資料應有
- 穩定 id
- 中文主名稱及其他別名
- 資料類型與最早／最晚活躍年代（可未知）
- `canon_status`: `verified` / `needs_verification` / `inferred` / `original_game`
- `sources`: 可核對的卷、章、連結、註記
- `notes`: 考據疑點、時間線相容性

## 時間與組織名錄
- 不能僅根據「一個名錄上列出多少項」就稱「所有隱秘組織總數」。
- 區分：正式教會、官方非凡組織、隱秘組織、家族、派系、歷史組織、第二部新勢力。
- 同一組織的內部派系保留子 id，不自動計作兩個獨立組織。
- 原作有歷史事件不等於該組織在 1349 年仍可加入。
- 重要事實必須核對兩部原作的時間序列，避免年代錯置。

## 改動流程
提出變更 → 查原作 → 註記狀態與來源 → 確認對事件和角色的影響 → 提交。
