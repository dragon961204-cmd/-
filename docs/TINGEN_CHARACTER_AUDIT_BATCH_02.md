## 高優先級核對
- **廷根在場**、**某時曾加入值夜者**與**1349年當時任職**是三個不同的命題，必須獨立核實。
- 確認新增職員的正式中譯名、是否角色同名、是否無名角色被錯當人物。
- 查清倫納德的紅手套任職年份，不得在早期廷根事件直接使用其後期身分。
- 洛絡塔、博爾吉亞、格雷等條目需核對地方分隊與登場時段。
- 新增人物中，韋爾奇、娜婭、賽琳娜、瑞爾·比伯等暫列「未確認正式隸屬」，不等於原作肯定無組織。

- `nighthawks` 名錄中存在不同任職時期以及文職/非凡者分類，不能一律標記為戰鬥非凡者。
