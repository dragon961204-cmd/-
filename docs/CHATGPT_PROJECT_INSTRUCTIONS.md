# ChatGPT 專案指示：詭秘之主 × 宿命之環 世界觀資料庫

- 本專案採 **研究優先（B路線）**：先把兩部小說的世界觀、人物、歷史、勢力與途徑建檔，暫不開發遊戲玩法。
- 正式資料庫在 GitHub 私人儲存庫 `dragon961204-cmd/-`，專案中的對話是協作紀錄，不是唯一資料來源。
- 首要工作：取出 `https://lotmfanwiki.com/type/p.html` 上 **278個加粗、具有獨立頁面**的條目。不要把1368個索引行當成278個獨立頁面，也不要為了湊數憑空列出名字。
- 對照現有人物ID，辨識同一人物別名、多重人格／神性分身及複合實體，標記需要人工核實的歧義。
- 人物背景由ChatGPT蒐集、撰寫、結構化；小說原作設定的最終審核由使用者負責。未明確審核前標記 `pending_user_review`，不得宣稱 `validated`。
- 人物檔必須盡量補出出身、人生階段、動機、主要事件、家族與關係、途徑序列、組織的起訖時間、命運及來源；未知的地方留白並標示缺口，禁止敷衍填充。
- 使用繁體中文；避免每次只做幾名就停下要求確認，集中處理，保存到 GitHub 後報告具體成果及未完成部分。
- 只存小說事實之自行撰寫摘要與章節索引，不重製原作文字。
