# 廷根試玩｜原作基準與 IF 線驗收

[橋下的回信](../playtests/tingen/index.html) 可下載後用瀏覽器開啟。從危機前一週走到事後第一週；每個窗口只夠親自辦一趟差事。原作提供零介入的世界基準。分歧須有及時、足以影響事件的前因，後續主線與支線都讀同一個實際結果。

## 這輪的界線

| 項目 | 零介入 | 這版可改的條件 |
| --- | --- | --- |
| 廷根之變 | 梅高歐絲抵達黑荊棘，值夜者阻止降臨。 | 事件照期發生，外圍調度與證人安危可變。 |
| 核心交鋒 | 鄧恩犧牲，克萊恩死亡、復生並離開廷根。 | 這版的干預集中在側門交接，核心交鋒沿原作。 |
| 聖賽琳娜骨灰 | 因斯取得骨灰。 | 先讓黑荊棘核實預警並調派外圍人手，再於危機當日把有問題的調令及時交給側門守衛。守衛核對並阻止交接，因斯撤離，骨灰由黑荊棘收回入庫。 |
| 下一週的案卷 | 已確認失竊且有調查聯絡，才可循失竊時刻追查。 | 骨灰留在黑荊棘時，失竊案未成立；由實際保住的假調令開啟接應者查訪。 |

假調令、側門接應者及玩家能在當場阻斷交接的流程為遊戲原創。原作基準依[廷根年表](../../lore/history/tingen_1349_v1.json)及[廷根之變正文](tingen_crisis_story_v1.md)。廷根之變與大霧霾仍是既定事件；要改變任一事件的其他核心結果，須先寫出能在當場作用的前因及下游改動。

## 主線如何改動支線

- **骨灰失竊。** 玩家持有可信證詞及調查聯絡時，可用案卷上的交接時間核對出城紀錄。後段若有任務要求因斯帶著骨灰、或用骨灰定位他的行動，須檢查骨灰的當期持有人及證據。
- **骨灰留庫。** 同一案卷讀取現持有人為黑荊棘，關閉以失竊為前提的任務。守衛實際留住假調令時，改從收件地址追查接應者。若日後出現新的失竊，須由新的已結算事件改寫持有人。
- **因斯仍可能被追查。** 出場、路線與盟友依其他可核實證據另行重算。後段的因斯案可以由獨立線索接回；前因已改的情節須依新結果重寫。
- **玩家知情。** 畫面依實際收件、親歷或有權告知的人更新；人脈、暴露與證物狀態由選項變化、回信和接應呈現。

## 重跑與驗收

| 選擇 | 事後第一週 |
| --- | --- |
| 通報黑荊棘 → 把假調令交側門守衛 | 骨灰留庫，可追查接應者。失竊案不出現。 |
| 通報黑荊棘 → 留在正門具名作證 | 骨灰被奪，可跟進失竊案或赴黑荊棘回訪。假調令查訪不出現。 |
| 確認橋下房間 → 護送證人 | 骨灰被奪；可回訪證人、取得獲准轉交的證詞。 |
| 交出倉庫路線 → 核實新門 | 骨灰被奪；可到新址赴約，舊門已撤。 |
| 照常離開 → 離開現場 | 世界走原作基準；玩家只能讀公開善後。 |

已在瀏覽器各走一次失竊線與留庫線，確認互斥的回訪選項和實際交付。另以 JavaScript 枚舉 23 種可走到底的組合，確認只有成功守側門才改變骨灰去向。後續每條 IF 線都須重跑零介入、及時介入與錯過時機，並列明哪些下游場景開啟、改寫或失效。
