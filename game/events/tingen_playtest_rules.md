# 廷根試玩｜原作界線與驗收

試玩檔 [橋下的回信](../playtests/tingen/index.html) 可下載後直接用瀏覽器開啟。從危機前一週切入，經過危機當日，到事後第一週完成一次回訪。三種主動走法及零介入共用同一個起點、同一場危機與同一套行動規則。每個窗口限定一趟親自辦的差事，用來讓取捨可以比較。

## 驗收

同一開局已有獲准的病院節錄、核對過的倉庫巷線索及可詢問的石橋接應。三趟準備共用截止時間。點「回到同一個起點」可重跑。

| 操作順序 | 事後第一週必須可做 | 實際取得與代價 |
| --- | --- | --- |
| 通報黑荊棘 → 具名作證 | 黑荊棘回訪 | 獲准的案卷節錄與後續查訪。姓名入卷。 |
| 確認橋下房間 → 護送證人 | 石橋回訪 | 安全落腳點及經本人授權的證詞。教會須另收到證詞才能採用。 |
| 交路線給密修會 → 核實新門 | 新地址赴約 | 交易接頭方式。舊門撤走，接頭人已掌握玩家交出的路線。 |
| 照常離開 → 離開現場 | 公開善後 | 只能讀到可公開的消息。 |

在瀏覽器完成以上四條走法，確認三個專屬回訪分別出現。另以 JavaScript 枚舉 20 種可走到底的選擇組合，確認核心世界結果一致。已訂房但未護送時，事後不開證人回訪；交過路線但沒追上接頭人時，只能查舊門，不能直接赴新址交易。

## 後續驗收標準

每個大事件先列不可動與可動欄位，再從同一起點驗證至少三條有實質差異的走法。比較下一週可用行動，以及各自留下的人際關係、資源、暴露與風險。若三條最後開出相同的一組行動，先修該事件的後果及其下一週，再擴寫後段。另跑一次零介入，確認世界照既有基準推進。
