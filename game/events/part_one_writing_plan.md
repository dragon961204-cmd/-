# 第一部文本工作計畫

本頁是新對話接續文本工作的入口。開始新一批之前，先讀本頁、相關時間線和既有支線稿。每批完成後更新本頁的進度和待議事項。

## 已確認

- 目前暫停 Demo 開發，回到文本工作。第一部統一從廷根開場，出生地暫停隨機抽取。工人家庭是第一個樣稿。
- 以原作為零介入基準。玩家可在事件中自由選擇派系，主動干預須符合取得的情報、能力與時限。長支線應能影響第一部主線或後續應對外神入侵的局勢，延伸段落標為遊戲原創。
- 第一部沿用既有的 01–14、17 共十五條長支線設計稿，含塔羅會。15、16 暫緩至第二部。約五十種結局是全遊戲目標。
- 逐日走訪時沿用一天最多五次的設計基準。信賴、精神狀態等隱藏變數透過對話、行為和敘述提示玩家。小事件需有可演出的場景、對話、選項與可見後果，保留獨立的城市日常。

## 時間推進提案｜待確認

- 世界使用同一條日曆，主線與各地支線到期照常發展。玩家可以手動過有選擇的日子，也可以在平靜期選擇上工、蒐集情報、消化魔藥或旅行，以數天到數週為單位推進。
- 快轉前提示玩家已知道的約定與期限，可縮短快轉或留在當天。快轉途中出現玩家能知悉且可採取行動的新狀況時，可以停下。已錯過的事依原有條件推進，之後可透過書信、報紙或人物反應得知。
- 若約一千兩百個世界日全開成手動日，最多會有約六千次走訪。手動日數、快轉粒度和各段文本數量由開場三日與第一段快轉的樣稿驗證後再估。
