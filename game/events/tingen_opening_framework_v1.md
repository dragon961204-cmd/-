# 廷根正式版開場框架｜半袋煤

範圍從輸入名字後的第一句，到七號貨棚的第一個重大選擇及其直接結果。沿用[〈半袋煤〉](tingen_opening_story_v1.md)與[《失蹤的夜班工》](tingen_sidequest_prologues_v1.md)。相對時段從同一日清晨到交班前，確切日期待定。本地案、艾德、貨棚與下列異象屬遊戲原創。

## 場景順序

| 幕 | 場景與人物 | 這幕要發生的事 |
| --- | --- | --- |
| 1 | 清晨・家中，母親 | 輸入名字後從「回來的時候帶點煤」開始。三枚銅便士、半塊麵包和母親叮囑別賒帳，交代主角家裡的日常。出門時主角只想買煤、準時上工。 |
| 2 | 清晨・河岸煤攤，艾德妻子 | 先從不同顏色的手套說清艾德與主角的關係。艾德妻子拿出欠條，問丈夫在哪裡頂班。主角親眼看過七號棚的正門被釘死，欠條卻記著三人從那裡下工。玩家可借原件當面問工頭，或把原件留給她、點名後私下問工友。 |
| 3 | 上工前後・工場，工頭與替班工友 | 工頭當眾闔上薪冊，或在點名後把無人領的信封放回抽屜，兩個版本各演一次。工友說出艾德是替他頂班，拿出七號銅牌，交代自己何時能在河門接應。若主角公開追問，工頭知道他在查七號棚；私下詢問則保住這次談話。 |
| 4 | 交班前・七號棚外，艾德 | 三聲敲擊先讓主角確認棚內有人。艾德報出身分，說自己還能走，請主角看看河門。主角從門縫往裡看，發現一串仍濕的泥腳印沿牆延伸到天花板。讓主角停一拍，再聽見艾德問「你還在嗎？」這是主角首次親眼接觸異常。主角只能確認自己所見，還不知道原因。 |
| 5 | 同一刻・側門與河門之間 | 主角已知艾德能走、河門可以接應、交班後守夜人會回到側門，當前的救人窗口很短。艾德問主角打算從哪邊帶他出去。玩家以台詞作出重大選擇，隨即讀到對應結果。 |

前段的欠條選擇用來改變證物和誰察覺調查。棚外選擇改變艾德去向與之後的證詞入口。舞台上的異常逐步升高，從不合常理的欠條、無人領的工錢，走到肉眼看見的泥腳印。首次看見異象後，先留一拍給主角反應，再把注意力拉回艾德能否離開。

## 第一個重大選擇｜在交班前怎麼救艾德

| 主角說出口的話 | 直接結果 | 後續帶走的狀態 |
| --- | --- | --- |
| 「我從側門撬開。等我叫你，你再出來。」 | 趁交班撬門，艾德扶牆走出。守夜人回頭看見主角手上的撬棍。艾德到巷口後才說出值班簿被送往河邊辦事房。 | 艾德脫困。守夜人能描述主角。辦事房線索為艾德轉述。 |
| 「我去叫替你接班的人。等你聽見短哨，再走河門。」 | 工友在約定的時段接應，艾德從河門出去。離開後，艾德在舊船票上畫下辦事房的位置。 | 艾德脫困。工友成為接應知情者；守夜人未在側門目擊主角撬門。主角取得標有位置的舊船票。 |
| 「我先去找人。你等我回來，先別出聲。」 | 主角去找能幫忙的人。回來時貨棚已換鎖，敲門無人回應；艾德在交班後被移走，主角暫時不知道去向。 | 艾德被移走，沒有可立即聯絡的艾德證詞。主角仍可用此前已見過的欠條資訊或工友線索，後續查證辦事房的轉運紀錄。 |

側門方案需要主角已確認門能撬開、守夜人正交班；河門方案需要工友已答應接應且仍能趕上。這兩個前提在選擇前交代。前段選擇公開或私下問話，主要改變誰知道主角查過案，兩種問法都能取得接應線索。第三個選項的風險在開口前已交代，艾德被移走不等於已死亡。

## 選擇結算後的交接

- 保存艾德的實際去向、欠條原件持有人、舊船票是否取得、工頭和守夜人各知道多少，以及主角自己看到和聽到的內容。
- 艾德脫困時，下一段可接他安置女兒或決定是否具名作證。主角曾救他，仍需取得他的同意才能交出姓名。
- 艾德被移走時，下一段可接匿名提報、主角就親眼所見具名，或去辦事房查紀錄。值夜者繼續依自身線索調查。
- 七號貨棚與河對岸的筆記案倉庫是兩個地點。後續要查到貨物二次轉運，才接[倉庫案](tingen_warehouse_story_v1.md)。本段在首次選擇的結果落地時收束，主角仍為普通人。
