# 第一部｜22 條途徑的晉升時機

依[第一部工作計畫](part_one_writing_plan.md)排定。下表安排玩家的事件窗口，原作人物的晉升仍循各自年表。序列名稱沿[途徑資料](../../lore/pathways/pathway_registry_v1.json)。未寫成正文的接點是遊戲排程。既有正文若已指定更細的條件，該場景沿原條件結算。

- **時間起算。** 首服後開始看序列 8，上一次實際晉升後開始看下一階。約三至四個月是低、中序列首輪接觸的排程參考。下表同時要看事件是否開啟；海上三條途徑的細部時差以[航程正文](backlund_voyage_and_bayam_arrival_story_v1.md)為準。
- **邀約與晉升。** 先記到場、導師、持有的配方及材料，再確認消化和適用儀式。玩家同意且實際完成服藥，才更新序列。來源中斷、選擇拒絕或錯過主線後，可從可用的回訪或可信替代供應重新開窗。首服很晚時，可能在第一部結束前都等不到下次機會。
- **跨線。** 同一條途徑只記一份服藥與消化進度。換派系或供應人時，按新窗口查證供應資格與人脈。當週有特殊事件才切進正文。沒觸發時，照週推進。玩家介面以回信、約見、熟練感與當事人的判斷提示進度。
- **高序列。** 序列 4 起按途徑與儀式另定事件窗。可用前置分布在後段戰事、陵寢、遠征及末卷權柄事件。只有該途徑條件和世界狀態都成立才開放；相同事件可只提供證據、人手或撤離條件。序列 3 至 0 的個別窗口隨各條後段正文確定，序列 0 另讀權柄的實際狀態。早期排程可以抵達第一部尾聲而停在任何已完成的序列。
