| 原作節點 | 觸發與遊戲分歧 |
| --- | --- |
| 貝克蘭德追捕 | 追兵到場、反擊尚未發生，且玩家在本地接觸酒吧人脈或查到對卡斯帕斯的施壓。玩家可向馬里奇通報、替追兵追查接應點、協助撤離或保持獨立。先交出的情報會改變雙方部署，之後轉向仍須面對其後果。零介入時，莎倫、馬里奇與夏洛克設局，史蒂夫與傑森死亡，追捕瓦解。 |
| 海上與拜亞姆 | 蕾妮特與克萊恩建立信使契約。斯厄阿隔空介入拜亞姆交鋒，考特曼等力量出手。信使契約與拜亞姆各自按原作推進。玩家可從地方接應人進入放縱派路線，或向節制派、風暴教會示警。可改變的是誰預先備妥接應、誰能撤走、地方據點是否暴露。 |
| 木乃伊與陵寢 | 莎倫、馬里奇請克萊恩協助取得圖坦西斯二世木乃伊。前段取得信任的玩家可協助查路線、接應或交接。其他玩家可經可信中間人進入。放縱派合作者可以追查對方行動、交換線索或私下示警。蕾妮特是否出手取決於自身目的、狀態與對玩家的信任。木乃伊和陵寢之戰的細部銜接待核。 |

## 04｜值夜者與廷根之變

核心人物為鄧恩、克萊恩、倫納德、老尼爾、因斯·贊格威爾、蘭爾烏斯與梅高歐絲。戴莉、胡德·歐根與達克斯特各自提供調查接點。韋爾奇與娜婭是開篇案件關係人，開局按筆記事件已發生處理。聖賽琳娜骨灰和封印物 0-08 的內情依玩家查到的證據開放。

| 階段 | 觸發與遊戲分歧 |
| --- | --- |
| 筆記與異常死亡 | **全遊戲最早可改變原作事件的候選點。** 調查已開始，玩家在廷根並能接觸黑荊棘、案件關係人或可靠的街坊線索。可以先向值夜者提交可查證的線索、自行查證，或保留消息。首次能改變的是鄧恩何時收到情報、能否在證據消失前查訪。 |
| 黑荊棘與老尼爾 | 取得值夜者的合作資格，或透過可信關係接觸老尼爾。玩家可協助一般調查，或在發現異常後按證據示警。老尼爾的污染需具備相應的辨認能力或盟友。單次警告可以改變小隊的準備程度，阻止失控則須有更早的發現及可行的處置。 |
| 蘭爾烏斯與胡德 | 透過鐵礦募資、占卜俱樂部的求助或精神病院接觸案件。玩家可保護達克斯特、查證胡德與蘭爾烏斯的往來，或先向當地人預警。與 03 共用同一份通報時間、證人暴露與證據狀態。梅高歐絲是遭利用的人，救援與阻止降臨各有行動條件。 |
| 梅高歐絲抵達黑荊棘 | 玩家在危機前取得可靠證據並通知有能力處置的人，才能改變小隊部署。凡人或低序列玩家可以疏散、傳訊和保全證據。要改變鄧恩的生死或因斯奪取骨灰的結果，須有能阻斷相關環節的事前準備和合適戰力。 |

## 05｜極光會的降臨計畫
