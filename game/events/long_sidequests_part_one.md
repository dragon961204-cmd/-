## 01｜玫瑰學派內鬥

蕾妮特·緹尼科爾與斯厄阿是兩派的核心人物。斯厄阿在人物資料庫使用「斯亞」，人物 ID 為 `suah`。莎倫、馬里奇及卡斯帕斯提供節制派與地下圈入口。史蒂夫、傑森、泰爾代表追兵，夏洛克按自身取得的情報行動。

| 原作節點 | 觸發與遊戲分歧 |
| --- | --- |
| 貝克蘭德追捕 | 追兵到場、反擊尚未發生，且玩家在本地接觸酒吧人脈或查到對卡斯帕斯的施壓。玩家可向馬里奇通報、替追兵追查接應點、協助撤離或保持獨立。先交出的情報會改變雙方部署，之後轉向仍須面對其後果。零介入時，莎倫、馬里奇與夏洛克設局，史蒂夫與傑森死亡，追捕瓦解。 |
| 海上與拜亞姆 | 蕾妮特與克萊恩建立信使契約。斯厄阿隔空介入拜亞姆交鋒，考特曼等力量出手。信使契約與拜亞姆各自按原作推進。玩家可從地方接應人進入放縱派路線，或向節制派、風暴教會示警。可改變的是誰預先備妥接應、誰能撤走、地方據點是否暴露。 |
| 木乃伊與陵寢 | 莎倫、馬里奇請克萊恩協助取得圖坦西斯二世木乃伊。前段取得信任的玩家可協助查路線、接應或交接。其他玩家可經可信中間人進入。放縱派合作者可以追查對方行動、交換線索或私下示警。蕾妮特是否出手取決於自身目的、狀態與對玩家的信任。木乃伊和陵寢之戰的細部銜接待核。 |

**第一部結算**記錄莎倫與馬里奇是否仍可聯絡、蕾妮特是否願意合作、斯厄阿一方的拜亞姆接應是否仍在、木乃伊去向與玩家欠下的承諾。這些結果供日後末日撤離及追查污染來源使用。兩派整體勝負仍懸而未決。

## 02｜魔女教派與大霧霾

| 原作節點 | 觸發與遊戲分歧 |
| --- | --- |
| 雪倫夫人案 | 圍捕前接觸委託方、黑荊棘或雪倫的社交圈。可交證據、替雪倫示警或追查聯絡人。原作中肯利犧牲，雪倫被克萊恩擊殺。玩家須提前提供足以改變部署的情報，才可能改變當晚的傷亡。 |
| 紅薔薇莊園與大霧霾 | 從塔利姆的死因、埃德薩克的人脈或教派外圍入手。可幫特莉絲脫身、把行蹤交給教派，或以庇護換取王室線索。潘娜蒂亞參與獻祭，A 先生另有降臨儀式。有效預警可以救下一批居民。要提前中止災難，須在爆發前查到儀式、找到能出手的盟友並讓對方來得及行動。 |

| 復仇與末卷交鋒 | 特莉絲追查埃德薩克之死，潘娜蒂亞在迷霧小鎮的遭遇另按原作推進，奇克在末卷介入愚者晉升。玩家能否再次接觸特莉絲，取決於過去有沒有幫她、洩露行蹤或握有可信證據。能否直接介入高位事件取決於前段累積的能力與盟友。 |

## 03｜心理煉金會

奧黛麗、赫溫·蘭比斯與赫密斯是核心。達克斯特·古德里安與胡德·歐根是廷根入口，伊思蘭特引介研討會，蘇茜提供獨立觀察。玩家依事件選擇入會、外部合作、反制精神操控，或協助施加操控的一方。

| 原作節點 | 觸發與遊戲分歧 |
| --- | --- |
| 胡德·歐根失常 | 從醫院、地下材料交易或值夜者調查接觸達克斯特。及早通報可以改變值夜者掌握線索的時間，也可能暴露他。替他保密有機會取得組織引介。與 04 共用同一事件和後果。 |
| 伊思蘭特的研討會 | 有可信引介或已取得圈內人的信任。可求學、接委託爭取入會或向外部盟友提供消息。奧黛麗的塔羅會身分依 17 的事件與知情條件取得。 |
| 反制赫溫 | 在原作反制前接觸當事人並取得可交叉驗證的跡象。可示警、保護證人、封存證據，或協助赫溫追查調查者。原作基準是奧黛麗察覺精神干預並藉準備與塔羅會支援反制。 |
| 第一部末段的評議團 | 會內玩家可爭取參與調查，外部玩家可透過可信成員求援。赫密斯以「暴怒」身分活動，其親自接觸玩家需要符合事件分量。職務與晉升的精確章次待核。 |

**第一部結算**記錄哪些人能自主行動、誰願意作證、證據由誰保管，以及玩家能否取得可信的觀眾途徑支援。提早找到接應者可以同時保人與保全證據。曾替赫溫掩蓋精神干預的紀錄可影響評議團對玩家的信任。

## 04｜值夜者與廷根之變

核心人物為鄧恩、克萊恩、倫納德、老尼爾、因斯·贊格威爾、蘭爾烏斯與梅高歐絲。戴莉、胡德·歐根與達克斯特各自提供調查接點。韋爾奇與娜婭是開篇案件關係人，開局按筆記事件已發生處理。聖賽琳娜骨灰和封印物 0-08 的內情依玩家查到的證據開放。

| 階段 | 觸發與遊戲分歧 |
| --- | --- |
| 筆記與異常死亡 | **全遊戲最早可改變原作事件的候選點。** 調查已開始，玩家在廷根並能接觸黑荊棘、案件關係人或可靠的街坊線索。可以先向值夜者提交可查證的線索、自行查證，或保留消息。首次能改變的是鄧恩何時收到情報、能否在證據消失前查訪。 |
| 黑荊棘與老尼爾 | 取得值夜者的合作資格，或透過可信關係接觸老尼爾。玩家可協助一般調查，或在發現異常後按證據示警。老尼爾的污染需具備相應的辨認能力或盟友。單次警告可以改變小隊的準備程度，阻止失控則須有更早的發現及可行的處置。 |
| 蘭爾烏斯與胡德 | 透過鐵礦募資、占卜俱樂部的求助或精神病院接觸案件。玩家可保護達克斯特、查證胡德與蘭爾烏斯的往來，或先向當地人預警。與 03 共用同一份通報時間、證人暴露與證據狀態。梅高歐絲是遭利用的人，救援與阻止降臨各有行動條件。 |
| 梅高歐絲抵達黑荊棘 | 玩家在危機前取得可靠證據並通知有能力處置的人，才能改變小隊部署。凡人或低序列玩家可以疏散、傳訊和保全證據。要改變鄧恩的生死或因斯奪取骨灰的結果，須有能阻斷相關環節的事前準備和合適戰力。 |
| 事後追查 | 是否能接觸倫納德的追查，取決於玩家保有的證據與信任。克萊恩的復生與離城是原作後續，玩家依目擊或當事人透露得知。若玩家已改變危機結果，後續追查依實際人員、證物與去向重算。 |

**零介入基準**是廷根小隊阻止降臨，梅高歐絲與胎兒被消滅，鄧恩犧牲，克萊恩死亡後復生離開廷根，因斯取得骨灰。**第一部結算**記錄小隊和證人的存亡、骨灰去向、因斯的追查線索、黑荊棘與玩家的信任。能保住證人、阻止骨灰失竊和改變戰鬥傷亡，各自需要前因。這些結果分別影響日後能召集的人手與能證明的案情。

## 05｜極光會的降臨計畫

A 先生、X 先生和祕之聖者博提斯是第一部各階段的極光會人物。真實造物主是其信仰核心。蘭爾烏斯與梅高歐絲提供廷根事件接點，克萊恩、佛爾思、嘉德麗雅、奧黛麗與休依原作階段介入。參加聚會、接受委託及正式入會各有門檻。玩家可以在事件中選擇與極光會合作、從外部調查或保持獨立，轉向後仍須面對已交出的情報。

| 原作節點 | 觸發與遊戲分歧 |
| --- | --- |
| 廷根與碼頭區的蘭爾烏斯 | 廷根從鐵礦募資、胡德或值夜者調查接觸。蘭爾烏斯離開廷根後，玩家若在貝克蘭德取得可信的身份線索，可經碼頭追查。可以通報值夜者、私下跟蹤或協助掩護。若 04 已改變蘭爾烏斯的去向，碼頭事件依實際狀態觸發。原作基準是克萊恩找到他並向教會通報，追擊後在下水道殺死他。 |
| A 先生的非凡者聚會 | 須在貝克蘭德、聚會仍在運作，並由熟客引介或取得可查證的邀請。玩家可以交易材料、接下外圍委託或調查尋找愚者相關人士的動向。接受委託能取得下一個聯絡點，只有完成與入會相關的事件才會改變組織身分。玩家知道的塔羅會情報依 17 的知情條件取得。 |
| 大霧霾與降臨儀式 | 須在大霧霾前取得可核對的入口或運送線索，或在爆發後抵達仍可通行的區域。可協助疏散、帶路給有能力介入的盟友、截住外圍物資，或替 A 先生維持接應。低序列玩家的行動可改變誰能進入現場及何時抵達。直接改變儀式結果須有合適戰力及時間。原作基準是克萊恩在地下與 A 先生交鋒，降臨未成。A 先生此後仍有活動，最終遭抹除。 |
| X 先生的尋人委託 | 聚會仍在運作時，可由佛爾思的情報、地下委託或 X 先生的接應進入。可查證他正在找誰、保護被盯上的人、示警或提供消息。原作基準是克萊恩在聚會殺死 X 先生，軍情九處事後追查，休接下調查委託。事件改變後，休收到的案情也隨結果改變。 |
| 博提斯與舊日之盒 | 在伏擊前須經亞伯拉罕家族、塔羅會成員或極光會人脈獲得可靠線索。玩家可協助佛爾思與接應者、向博提斯示警，或追蹤盒子的去向。原作基準是佛爾思被盒子擄走，嘉德麗雅與奧黛麗截擊，博提斯死後盒子落入塔羅會手中。與 07、17 共用一份人物、交鋒與物品狀態。 |

**大霧霾與 02 共用一次事件結算。** 分別記錄疏散結果、潘娜蒂亞一方的獻祭進度、A 先生一方的降臨進度、證據去向與當事人能否撤離。來自兩條線的有效行動都能改變同一場危機。若玩家只切斷其中一方的外圍接應，另一方仍依自身條件行動。

**第一部結算**記錄被保護的目標、極光會仍可用的地方接應、玩家暴露程度、降臨證據的持有人與舊日之盒去向。早期混入聚會的玩家可能在尾聲收到殘存人脈的邀約。救下目標並交出可信證據的玩家，則可能取得教會或塔羅會的後續合作。這些結果供日後阻止降臨與跨勢力救援使用。
