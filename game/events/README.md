[第一部長支線總綱](part_one_sidequest_master_outline.md)整合十五條支線、主線交會、晉升接點與第一批場景綱要。

[胡德與蘭爾烏斯正文](tingen_hood_and_lanevus_story_v1.md)接續 03、04、05，收錄病院和代收鋪的查證、證人分歧及觀眾至讀心者的首輪機會。
