# 廷根篇

從專案根目錄執行 `python3 -m http.server 8000`，開啟 [廷根篇](http://localhost:8000/game/playtests/tingen-story/)。

故事從工人家庭的《半袋煤》開始，接到欠條與夜班工，再透過貨棚或俱樂部的退件進入筆記案。病院與募資、借閱簿與花店回條、廷根之變和事後查訪依 [第一部劇情總樹](../../events/part_one_story_tree.md) 排列。遊戲日期是本版排程。故事正文與 [事件 JSON](../../events/data/tingen-story.json) 可各自查閱。

每次走訪花 1 AP。事件完成後，當日仍可在剩餘 AP 內處理其他事件；危機前、危機當日與事後各有一件來得及親自辦的差事。推進時跳到下一個有劇情的日期。錯過玩家的介入窗口，案件照世界原有線索推進。

在危機當日的黑荊棘存檔，可回到正門或側門的分歧點。側門要求先查到有授權的病院與募資證據，並在危機前完成通報。
